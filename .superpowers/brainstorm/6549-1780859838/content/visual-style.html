Visual Identity

What aesthetic should ChainGuard have? This sets the tone for every page.

A

Cyber Noir (Recommended)

Deep dark (#0a0a0f) with electric accent colors. Subtle grid/scan-line backgrounds. Glowing borders on active elements. Animated severity pulses. Think CrowdStrike Falcon meets Bloomberg Terminal.

bg → surface → cyan → red → purple → green
B

Splunk Native

Matches Splunk's own design language — dark charcoal, green/orange accents, familiar to Splunk users and judges. Professional but not flashy. Shows "this belongs in the Splunk ecosystem."

Splunk dark → panel → green → orange → red → blue
C

Clean Enterprise

Minimal, crisp dark theme with lots of whitespace. Blue/slate palette. No glow effects — relies on typography and spacing. Think Linear or Vercel dashboard. Modern SaaS feel.

zinc-950 → zinc-900 → blue → red → yellow → zinc-400
